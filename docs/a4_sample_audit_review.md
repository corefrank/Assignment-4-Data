# CS336 A4 — 人工抽样质量审计（seed=336）

> 数据来源：本地真实 Common Crawl WET Pipeline 的 `audit_samples.md`，每项仅依据所提供的文字摘录判断，未复核完整网页。目标：评估语料对英文 C4 100 domains 语言建模任务的适用性。

## Five randomly selected final kept examples

1. **Kept 1 — Epiq 法律专家介绍**：网页包含可读的法律服务介绍，但大量导航栏（Expand Solutions/Industries 等）和营销叙述降低了有效自然语言密度。可保留正文段落，但不是高质量训练语料的优先选择。
2. **Kept 2 — WVXU 新闻报道**：文章提供相对完整的新闻事实和上下文，语言连贯，适合英语语言模型训练。开头的广播频道切换和播放状态属于可进一步去除的模板噪声。
3. **Kept 3 — 律师事务所人事公告**：正文基本规范，但内容以律所人员招聘和品牌宣传为主，信息量与语言多样性有限。对于通用英文预训练，可以降低此类公司公关稿的优先级。
4. **Kept 4 — 焦虑与脑科学科普文章**：样本包含连续的科普解释文字，具有较好的语言建模价值。文章时间较早，涉及医学事实时需注意时效性，不能仅凭文本流畅性判断事实可靠。
5. **Kept 5 — 二手音频设备目录**：文本以技术参数、数字、设备型号和商品列表组成，缺少完整自然语言论述。对于以 C4 类网页正文为目标的语料，可以考虑增加目录页过滤，但不要仅因含技术规格就删除所有技术文档。

## Five randomly selected discarded examples

1. **Rejected 1 — 葡萄牙语电气商城（language）**：主体语言为葡萄牙语，且包含商品导航。对目标为英文的语料而言，语言过滤合理。
2. **Rejected 2 — Tromsø 旅游目录（gopher）**：摘录中浏览器提示、季节、地区、菜单和导航项密集，正文较少。Gopher 规则删除有一定合理性，但仅凭摘录无法断言整篇内容都不适合训练。
3. **Rejected 3 — 西班牙语农业新闻（language）**：正文为西班牙语新闻，且包含站点菜单信息。即使新闻内容本身可能有信息价值，也不满足英文训练语料的目标，因此删除合理。
4. **Rejected 4 — 俄语加密货币记录（language）**：正文主要为俄语及交易数字记录，英文成分不足。语言过滤合理。
5. **Rejected 5 — 俄语共享办公网站（language）**：主体导航与说明为俄语，虽然夹杂英语短句，仍不属于纯英文训练正文。语言过滤合理。

## 下一轮实验假设

Baseline 的主要问题不是非英文文本，而是保留下来的英语网页中仍存在菜单模板、重复 n-gram、目录式文本。采用语言筛选 + Gopher + NSFW/Toxic + PII 作为 Baseline；在 Strong 设置里追加通用重复短语、导航密度与词汇多样性规则。使用相同的真实 WET 文件比较保留率、各过滤阶段的拒绝数、去重后文档数、token 数和人工抽样质量。**不能以过滤更多或者 token 更少直接推断 Paloma loss 更好。**
